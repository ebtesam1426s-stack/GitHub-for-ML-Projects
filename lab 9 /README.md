# Decision Trees & Random Forest Project

A simple ML project using Decision Tree and Random Forest models to predict whether a loan is fully paid or not.

## Steps
- Cleaned the data and created dummy variables.
- Split the data into train/test sets.
- Trained a Decision Tree model.
- Trained a Random Forest model.
- Evaluated both models using confusion matrix and classification report.

## Results
- Random Forest performed better overall.
- Both models struggled with the minority class due to class imbalance.

## Conclusion
Random Forest is more accurate and stable than a single Decision Tree.
