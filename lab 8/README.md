# KNN Classification - Lab 8

This project applies the K-Nearest Neighbors (KNN) algorithm for a binary classification task.

## Steps
- Load and explore the dataset.
- Scale features using StandardScaler.
- Split data into training and testing sets.
- Train a KNN model.
- Evaluate using confusion matrix and classification report.
- Use the elbow method to choose the best K.
- Retrain the model with the selected K value.

## Result
Using K = 30, the model achieved around 0.84 accuracy.
